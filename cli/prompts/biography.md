**General Analysis Focus (Biography):**

- Chronology: life periods, turning points, transitions
- Places: cities/regions, migrations, travel routes, lived environments
- People: family, mentors, collaborators, rivals; key relationships
- Work & roles: jobs, projects, institutions; how roles changed over time
- Lived experience: routines, hardships, successes, failures, constraints
- Anecdotes: specific incidents/scenes that reveal character or context
- Cause/effect: why moves/choices happened; consequences; inflection moments
- Dates & ages: anchored time markers (years, ages, eras) when stated

**Content Priorities:**

- One card = one life phase OR one pivotal event OR one defining relationship/theme
- Anchor each card in time + place when available (year/age + location)
- Prefer concrete biographical facts: “who/what/when/where” over abstract traits
- Capture “before → trigger → after” for major transitions (career shift, relocation, breakup, etc.)
- Keep anecdotes only if they contain specific names/places/objects/actions
- Avoid author interpretation; stick to what the text states or strongly implies

**Card Construction Rules (Biography):**

- Front (`##`) is a compact prompt: event/period + time marker (if known)
  - Examples: “Paris years (1890–1895)”, “Move to New York (age 27)”, “War service”
- Back bullets (1–3) must be concrete fragments:
  - time marker (year/age/era) + place
  - key actors (names/roles)
  - outcome/impact (career, relationship, health, worldview), if explicit

**Format Requirements:**

- Return only Markdown flashcards; no deck title, no commentary, no wrappers
- Each card front is a `##` heading; keep it concise and specific
- Each card back is a bullet list starting with `-`; nest sub-items by indenting two spaces
- Leave a blank line after each `##` heading and one between cards
- Never emit a `#` heading; the deck title is added separately, and a `#` here would end the card above it
- 1–3 top-level bullets is a good heuristic rather than a hard cap; prefer 3 when the source allows
- Bullet items are terse fragments (not sentences) surfacing concrete facts/names

**Avoid:**

- Complete sentences or filler words
- Explanations, opinions, or meta-commentary
- Psychological speculation (“felt”, “wanted”) unless explicitly stated
- Redundant points already covered elsewhere
- Trivial details not tied to a life period/event/relationship/theme
- Returning code fences unless they already exist in the source material
